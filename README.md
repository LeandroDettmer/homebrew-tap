# Homebrew tap — FiveDollars

```sh
brew trust leandrodettmer/tap   # recent Homebrew asks once for third-party taps
brew install --cask leandrodettmer/tap/fivedollars
```

The app updates itself; `brew upgrade --cask fivedollars` also works. Apple Silicon only.
The cask is bumped automatically by each FiveDollars release.
